标准长 JSON 详情

点击顶部请求体，确认它与响应体一样可进入 Sources 对象树。

Sources 深层筛选

搜索 needle，应只展开命中路径；清空或改词后路径仍保持展开。

真实 GET 请求

带查询参数和 120 行响应；发送后请从 Network 列表点开。

真实 POST 请求

带 JSON 请求体、自定义请求头和 201 JSON 响应。

超大 JSON

响应超过 130 KB，用于检查 100 KB 显示上限和打开耗时。

密集关键词

直接构造 400 次匹配，应显示为 1/200+，切换时保持流畅。

无效 JSON

声明为 JSON 但内容不完整，应原样显示且不影响详情交互。

连续请求

并发发送 30 条 GET，检查 Network 列表和详情切换性能。

清空 Network

清理已产生的请求，方便从单一场景重新开始验收。
